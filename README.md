# 📊 Alura Store - Análisis de Tiendas para Recomendación de Venta

Este proyecto consiste en un análisis de datos para apoyar al Sr. Juan en la decisión de qué tienda de la cadena **Alura Store** debería vender para iniciar un nuevo emprendimiento.

A partir de datos de ventas, rendimiento y reseñas de clientes de **4 tiendas**, se busca identificar la sucursal menos eficiente y presentar una recomendación final basada en evidencia.

---

## 🎯 Objetivo

Evaluar el desempeño de las tiendas mediante métricas clave como:

- Ingresos totales  
- Categorías más vendidas  
- Productos más vendidos  
- Reseñas y satisfacción de clientes  
- Costo de envío promedio  

Con el fin de determinar cuál tienda representa la opción más adecuada para ser vendida.

---

## 🛠️ Tecnologías utilizadas

- **Python**
- **Pandas** (carga y manipulación de datos)
- **Matplotlib** (visualización de resultados)
- **Seaborn** (visualización de resultados)

---

## 📌 Actividades realizadas

✔ Carga y exploración de datos en formato CSV  
✔ Limpieza y transformación de información relevante  
✔ Análisis comparativo entre las 4 tiendas  
✔ Generación de visualizaciones para interpretar resultados  
✔ Recomendación final basada en métricas de eficiencia  

---

## 📈 Visualizaciones

El proyecto incluye al menos **3 tipos de gráficos**, como:

- Gráficos de barras  
- Gráficos circulares  
- Gráficos de dispersión  
- Otros según sea necesario  

Estos permiten presentar los hallazgos de forma clara y comprensible.

---

## 📝 Recomendación final

Al finalizar el análisis, se presenta un informe donde se explica:

- Qué tienda debería vender el Sr. Juan  
- Qué métricas justifican esta decisión  
- Comparación directa con las demás tiendas
